# 开放文本语义理解与用户需求洞察平台

<p align="center">

  <a href="README.zh-CN.md"><strong>简体中文</strong></a>
</p>

面向文本类数据与问卷类数据的用户需求分析平台原型。项目聚合来自不同业务系统、渠道和数据格式的多源异构信息，利用 BERT 等预训练语言模型及相关自然语言处理技术，对用户表达进行统一的语义理解，识别显性诉求与潜在需求，并进一步沉淀为可用于业务决策的用户画像。

项目适用于客户反馈、客服工单、用户访谈、问卷回答、产品评论、社交媒体内容、市场调研和需求池等场景。

## 项目定位

传统文本分析往往停留在关键词统计或情感分类层面，难以回答“用户真正需要什么”“不同用户群体有什么差异”等业务问题。本项目希望构建一条从数据采集到需求洞察的分析链路：

```text
多源数据接入
      ↓
文本清洗与统一表示
      ↓
预训练语言模型语义编码
      ↓
意图识别 / 情感分析 / 主题发现 / 需求抽取
      ↓
用户标签与画像构建
      ↓
产品优化、运营决策与市场洞察
```

## 核心能力

- **多源异构数据接入**：面向文本、问卷、访谈记录、工单、评论等数据建立统一分析入口。
- **文本语义理解**：使用 BERT 类预训练语言模型获取文本的上下文语义表示，支持后续分类、聚类和检索任务。
- **用户需求识别**：从用户自然表达中提取问题、目标、偏好、痛点、期望和未满足需求。
- **主题与意图发现**：识别用户集中讨论的主题、意图和需求变化趋势。
- **用户画像构建**：将用户的行为、反馈、偏好、情绪和需求标签进行汇总，形成结构化画像。
- **批量分析与服务化调用**：支持单条文本、批量文本和文本集合分析，便于接入业务数据管道。
- **可解释结果输出**：保留关键词、主题、情感、标签和统计信息，方便业务人员复核分析结论。

## 数据分析流程

### 1. 数据接入与统一建模

接收来自不同渠道的文本和问卷信息，统一记录用户标识、来源渠道、时间、文本内容、问卷字段和业务上下文，为后续跨来源分析提供基础。

### 2. 数据清洗与质量控制

完成格式转换、缺失值处理、重复内容识别、无效文本过滤、敏感信息脱敏和领域词表规范化，减少数据质量对模型结果的影响。

### 3. 语义表示与任务建模

通过 BERT 等预训练语言模型将文本转换为上下文语义向量，并根据具体任务构建需求分类、意图识别、情感分析、主题发现和相似文本检索能力。

### 4. 潜在需求分析

结合文本语义、问卷选项、用户历史反馈和群体特征，识别用户明确表达之外的潜在诉求，例如功能缺口、体验障碍、购买顾虑、服务期待和未满足需求。

### 5. 用户画像沉淀

将分析结果转化为可管理的用户标签和画像维度，包括兴趣偏好、关注主题、情绪状态、需求类型、问题频率、满意度和潜在购买意向等。

## API 能力

| 能力 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 健康检查 | GET | `/health` | 检查服务是否正常运行 |
| 就绪检查 | GET | `/ready` | 检查模型和依赖是否可用 |
| 单文本分析 | POST | `/api/v1/semantic/analyze` | 分析单条文本的语言、情感、关键词和统计信息 |
| 批量文本分析 | POST | `/api/v1/semantic/batch` | 对多条文本进行批量语义分析 |
| 主题发现 | POST | `/api/v1/discovery/topics` | 从文本集合中提取主题及其关键词 |
| OpenAPI 文档 | GET | `/api/docs` | 查看接口契约与服务文档 |

## 部署方式

### 本地运行

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 容器运行

```bash
docker build -t open-text-semantics:latest .
docker run --rm -p 8000:8000 open-text-semantics:latest
```

## 当前版本与后续方向

当前仓库提供一个可运行的服务化基线，用于验证数据结构、接口边界和分析流程。后续可逐步接入真实的预训练语言模型、领域数据集和生产级数据基础设施：

- 接入 BERT、RoBERTa、MacBERT、Sentence-BERT 等中文预训练模型。
- 建立需求分类、意图识别和用户标签的领域标注体系。
- 增加问卷结构化字段与开放文本的联合建模能力。
- 引入向量数据库，支持相似用户、相似需求和历史案例检索。
- 建立用户画像版本、标签生命周期和画像更新机制。
- 增加模型评测、人工审核、反馈回流和模型迭代闭环。
- 通过权限管理、数据脱敏、审计日志和租户隔离满足实际业务治理要求。

## 设计原则

1. **以用户需求为中心**：分析文本不是最终目的，识别用户问题和潜在诉求才是核心价值。
2. **数据与模型协同**：统一数据治理、领域知识和模型能力，避免只依赖通用模型输出。
3. **从单点分析走向画像沉淀**：将一次文本分析结果积累为持续更新的用户认知。
4. **结果可追溯、可解释**：保留来源、关键词、主题和模型结果，支持业务复核与质量评估。
